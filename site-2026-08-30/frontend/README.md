# AI Intelligence Hub Frontend

Next.js App Router frontend foundation with TypeScript, Tailwind CSS, shadcn/ui
conventions, and TanStack React Query.

## Development

```bash
npm install
copy .env.local.example .env.local
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
npm run format:check
```

The root repository README and `docs/` directory contain the full architecture guidance.
